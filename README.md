# Personal Portfolio Website

A modern, responsive multi-page personal portfolio website built with HTML, CSS, and JavaScript.

This project was created as a portfolio/demo website and can be customized for developers, freelancers, designers, students, and other professionals.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Multi-page website
- Home page
- About page
- Services page
- Projects page
- Experiments page
- Education page
- FAQ page
- Contact page
- Privacy Policy page
- Interactive FAQ accordion
- FAQ search and filtering
- Project/experiment filtering
- Contact form with Formspree integration
- Social media links
- Smooth scrolling and hover effects

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Formspree
- Boxicons
